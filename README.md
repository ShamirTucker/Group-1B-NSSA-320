# Group-1B-NSSA-320
Repository for Group 1B's project in NSSA 320. Small Business Web Application Build using Terraform and Ansible.

1 Small Business Web Application
Build a website for a fictional small business using WordPress and a separate MariaDB database
server. Use Terraform to provision the Azure infrastructure and Ansible to install the software, configure
the database connection, and manage the services. Use a small amount of sample content to
demonstrate that the application works.
Environment: Two Linux VMs in Azure, one for the website and one for the database.
Demonstration: Deploy the site, publish sample content, and apply a configuration change through
Ansible.
